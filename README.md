## 구성
- `index.html` / `style.css` / `main.js` : 청첩장 페이지
- `hall/` : 픽셀 온라인 웨딩홀 (제작 예정)
- `images/` : 사진 폴더

## 내용 고치는 곳
`main.js` 맨 위 `CONFIG` 에서 갤러리 사진 목록, 계좌번호를 바꿀 수 있어요.
부모님 성함은 `index.html` 의 인사말 섹션(`.couple`)에서 바꿔주세요.

## 사진 넣기
`images/` 폴더에 아래 이름으로 넣으면 자동으로 보여요.
- `main.jpg` : 메인 사진 (세로 3:4 추천)
- `g1.jpg` ~ `g6.jpg` : 갤러리
- `og-image.jpg` : 카톡 공유 썸네일 (1200x630 추천)
